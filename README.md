# Cartoons 🎀

A simple website showcasing some of my favorite cartoons and their characters.

## About the Project

I created this website to practice building a simple and responsive website using HTML and CSS. It includes different cartoons, their characters, images, and links to their episodes on YouTube.

## Features

- 🎨 Colorful and simple design
- 📺 Cartoon names with links to YouTube episodes
- 👤 Character cards with images and information
- 📱 Responsive design for mobile screens
- ✨ Hover effects on the cards

## Cartoons Included

- Winx Club
- Detective Conan
- My Little Pony
- LEGO Friends

## Technologies Used

- HTML
- CSS
- JavaScript

## What I Learned

While building this project, I practiced structuring a webpage with HTML, styling it with CSS, using Flexbox and Grid to arrange cards, making the website responsive, and adding links and images.

## AI Usage

I used AI as a helper for understanding coding concepts, debugging, and finding small mistakes in my code. The project was mainly built by me.
